F. 에러 실전 사례집

"안 돼요"가 아니라 콘솔의 붉은 메시지를 복사 → Claude에 그대로 전달. (디버깅이 뭔지는 H탭 만화)

Uncaught ReferenceError: firebase is not defined
원인 · Firebase SDK가 안 불러와짐(CDN 주소·순서).
Claude에: "콘솔에 'firebase is not defined'가 떠. SDK가 CDN으로 제대로 로드되는지, 스크립트 순서를 점검해 전체 코드를 다시 줘."
Missing or insufficient permissions
원인 · 보안 규칙이 읽기를 막음(의도된 경우) 또는 규칙 미게시.
점검: 규칙 '게시' 여부 확인. 화면에 목록을 보여줘야 하면 읽기 허용 규칙이 필요 — 용도에 맞게 Claude에 재작성 요청.
auth/unauthorized-domain
원인 · 배포 도메인이 Firebase에 미등록.
해결: Authentication → Settings → 승인된 도메인에 xxx.netlify.app 추가(B탭 7).
화면이 비거나 한글이 깨짐
원인 · 인코딩 누락, 또는 미리보기 환경의 외부 연결 차단.
해결: <meta charset="utf-8"> 확인 + Firebase 동작은 Netlify 배포 후 확인.

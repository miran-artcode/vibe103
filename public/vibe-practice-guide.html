service cloud.firestore {

  }

G. 복사 전용 키트

실습 중 그대로 복사해 쓰세요. (사전준비 → 패턴 → 규칙 → 배포 → 트러블슈팅 → 체크리스트)

0 · 사전 준비물 (연수 전 미리)
터미널에 순서대로
# 1) Node.js 설치 확인 (nodejs.org에서 LTS)
node -v
# 2) Firebase CLI 설치
npm install -g firebase-tools
# 3) 설치 확인
firebase --version
1 · 마법의 컨텍스트 패턴
AI 프롬프트 창에 붙여넣기
Firebase Firestore 사용. 서버 없는 정적 웹앱으로 만들어줘.
로그인은 익명 인증(Anonymous Auth), 이름·이메일은 절대 받지 마.
보안 규칙도 함께 — 테스트 모드(전체 공개) 금지, 읽기는 막아줘.
한 사람이 짧은 시간에 중복 제출하지 못하게. 최신 공식 문서 기준으로.
2 · 보안 규칙 (Rules 탭 → 붙여넣고 게시)
firestore.rules
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /posts/{id} {
      // 익명 로그인한 사람만 쓰기
      allow create: if request.auth != null;
      // 앱에서 읽기/수정 차단 (교사는 콘솔에서 열람)
      allow read, update, delete: if false;
    }
  }
}

내보낸 폴더에서 터미널

firebase deploy
출력 · 마지막 줄에 Hosting URL: https://◯◯◯.web.app 가 나옵니다.
